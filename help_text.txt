## Hello! This is the eye bee docks bot!!
Current Version: {}
The syntax is simple!
For a random paper in math HL, physics HL, or chemistry SL, you would write
```
/bee arg[m p c / h h s]
```
It's that simple! (spaces are optional, but slash is not)
### Additional flags!!
This will specify min and max years!!
```
/bee arg[m p c / h h s] min_year[2015] max_year[2018]
```
This will specify a specific year!!
```
/bee arg[m p c / h h s] specific_year[2018]
```
This will specify your paper!!
```
/bee arg[m p c / h h s] paper[2]
```
This will specify the number of repetitions (8-10 MAX)!!
```
/bee arg[m p c / h h s] repetitions[4]
```
This will specify your name!!
```
/bee arg[m p c / h h s] name["Sunny!"]
```
